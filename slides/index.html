└── SKILL.md
---
name: resumen-portada
description: Úsala cuando el usuario pida resumir,
  sintetizar o extraer las claves de un texto.

Transforma el texto en:
• un titular de 8 palabras
• tres claves
• el plot twist: el dato más sorprendente
• un siguiente paso

La diferencia importante

Siempre activo vs. cuando hace falta

AGENTS / CLAUDE

Reglas permanentes

  • Se cargan por ubicación.
  • Afectan a todo el proyecto.
  • Propósito, límites y convenciones.
Skill

Capacidad reutilizable

  • Se descubre por su descripción.
  • Se invoca implícita o explícitamente.
  • Contiene un procedimiento concreto.

Una herramienta ejecuta acciones. Un MCP conecta el agente con herramientas o datos externos.

Dentro del harness · 4/4

coverage.json

Un criterio, un estado y la evidencia que lo justifica.

passed
Probado; no se observó ningún fallo.
failed
Probado; existe al menos un hallazgo.
inapplicable
El criterio no aplica a la muestra.
cantTell
Falta evidencia para poder decidir.
untested
Todavía no se ha probado.

findings.json

Ejemplo abreviado de un problema trazable:

{
  "id": "contraste-fecha-evento",
  "status": "confirmed",
  "criterion": "1.4.3",
  "title": "La fecha tiene poco contraste",
  "impact": "serious",
  "observed": "#777 sobre #fff: 4,48:1",
  "expected": "Contraste mínimo de 4,5:1",
  "stepsToReproduce": ["Abrir Eventos", "Localizar la fecha"],
  "evidence": [{ "type": "axe", "reference": "runs/axe.json",
    "description": "Fallo color-contrast" }],
  "visualEvidence": { "status": "captured",
    "reference": "evidence/contraste-fecha.png",
    "description": "Fecha enmarcada en rojo",
    "annotation": "red-rectangle" }

Cobertura ≠ hallazgos13 / 19

Cómo se conectan los archivos

No empezamos de cero en cada ejercicio

Fijamos los límites

El encargo se convierte en scope.json.

Elegimos la muestra

Usamos el alcance y creamos inventory.json y sample.json.

Ejecutamos Axe

Usamos la muestra y guardamos resultados brutos en runs/.

Completamos la auditoría

Resultados + pruebas manuales producen cobertura, hallazgos e informe.

La salida de un ejercicio es el punto de partida del siguiente.

Primer radar

3
25 minutosAxe

Pasamos la inspección automática

Cread una skill que ejecute Axe sobre la muestra y conserve los resultados brutos.

  • Una ejecución dentro de runs/.
  • Manifiesto de herramientas y versiones.
  • Una señal enmarcada en rojo y capturada.
  • Límites de la automatización.
