# Encargo de Lúmina Store

Lúmina Store es una pequeña tienda online ficticia. El equipo quiere conocer las
barreras principales de la experiencia pública de compra antes de una nueva
versión.

## Lo que sabemos

- Producto: la fixture local `fixtures/demo-site/`.
- Objetivo: evaluación contra WCAG 2.2 nivel AA siguiendo WCAG-EM 2.0.
- Incluye: inicio, catálogo, detalle de producto y todo el proceso de compra.
- Incluye estados que aparecen al interactuar, como navegación abierta, diálogo
  de información y errores de formulario.
- Excluye: autenticación, área privada y pasarela de pago externa, porque no
  forman parte de esta demostración.
- Contexto acordado: Chromium de escritorio a 1280 × 720, teclado y tecnologías
  de asistencia habituales compatibles con HTML, CSS y JavaScript estándar.
- El equipo del taller puede aprobar el alcance y la selección en nombre del
  cliente ficticio cuando las decisiones estén justificadas.

La herramienta automática es solo una parte de la evaluación. El cliente no ha
pedido una puntuación ni una declaración automática de conformidad.
