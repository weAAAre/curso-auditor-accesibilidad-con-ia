# Encargo de auditoría de CityLights

El equipo quiere identificar y documentar las barreras de accesibilidad de la
experiencia pública de CityLights.

## Lo que sabemos

- Producto: `https://weaaare.github.io/curso-auditor-accesibilidad-con-ia/`.
- Objetivo: evaluación contra WCAG 2.2 nivel AA siguiendo WCAG-EM 2.0.
- Incluye: las páginas, funciones, estados y procesos pertenecientes a CityLights.
- Excluye: destinos externos enlazados desde CityLights.
- Contexto acordado: Chromium de escritorio a 1280 × 720, teclado y tecnologías
  de asistencia habituales compatibles con HTML, CSS y JavaScript estándar.
- El equipo del taller puede aprobar el alcance y la selección cuando las
  decisiones estén justificadas.

La herramienta automática es solo una parte de la evaluación. El cliente no ha
pedido una puntuación ni una declaración automática de conformidad.
