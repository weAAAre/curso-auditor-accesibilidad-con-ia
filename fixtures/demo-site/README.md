# Lúmina Store

Producto ficticio y local para que toda la clase evalúe exactamente la misma
experiencia. Contiene barreras de accesibilidad deliberadas; por esa razón el
linter no analiza esta carpeta.

No consultes una lista de “errores sembrados” durante los ejercicios. La fixture
es evidencia de prueba, no una respuesta cerrada: Axe no encontrará todas las
barreras y una auditoría requiere comprobaciones humanas.

El producto tiene seis páginas: inicio, catálogo, detalle de producto y las
tres vistas del proceso de compra situadas en `checkout/`. Inicio, detalle y
entrega contienen además estados que solo aparecen después de interactuar.
