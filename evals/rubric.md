# Rúbrica de evaluación de las skills

Puntúa cada dimensión de 0 a 2. La automatización no sustituye esta conversación
del equipo.

| Dimensión | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Fidelidad | Inventa o contradice la fuente | Tiene ambigüedades | Sigue y enlaza la metodología |
| Trazabilidad | No sabemos de dónde sale | Parte de la decisión está explicada | Cada decisión tiene razón y evidencia |
| Utilidad | Exige rehacer el trabajo | Ayuda con intervención constante | Otro equipo puede aplicarla |
| Límites | Declara conclusiones injustificadas | Advierte límites de forma genérica | Detiene y pide decisión humana cuando toca |
| Claridad | Solo la entiende un desarrollador | Mezcla lenguaje técnico y cotidiano | Diseñadores y desarrolladores entienden el resultado |

Una skill está lista para la clase si no obtiene ningún cero y suma al menos 8
puntos. Registrad también una frase: “La siguiente mejora sería…”.

En skills que evalúan criterios, la trazabilidad obtiene un cero si un problema
visualizable no incluye captura anotada o si omite justificar por qué una
evidencia visual no es posible.
