# Escenarios mínimos de evaluación

## Skill de alcance

- Caso normal: `audits/demo/brief.md`.
- Caso límite: encargo sin estándar, nivel ni exclusiones.
- Caso negativo: petición de “pasar Axe”; la skill no debería activarse.

## Skill de mapa y selección

- Caso normal: la fixture del curso.
- Caso límite: producto pequeño; debe contemplar evaluar el conjunto completo.
- Caso negativo: no existe alcance aprobado; debe detenerse.

## Skill de Axe

- Caso normal: muestra aprobada con un estado interactivo.
- Caso límite: una vista no carga o un selector de interacción no existe.
- Caso negativo: no existe `sample.json` aprobado; debe detenerse.

Para comparar versiones, empieza una conversación limpia y utiliza el mismo
encargo. Conserva el resultado, aplica la rúbrica y cambia solo lo necesario.
